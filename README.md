# :book: AI Tools for Academic Uses

The launch of ChatGPT sparked a transformation across many fields, and academia is no exception. Since then, a rapidly growing ecosystem of AI-powered tools has emerged to support researchers at every stage of the research process -- from discovering and reviewing literature to writing, summarizing, and analyzing data. This repository curates a selection of these tools across key categories. The list is updated regularly to reflect the latest developments.
